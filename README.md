# Shorten-URL-using-tkinter
A simple URL shortener built using Python and Tkinter, leveraging the `pyshorteners` library to convert long URLs into shorter ones using TinyURL.  

## Features  
- User-friendly GUI built with Tkinter  
- Converts long URLs into short ones using TinyURL  
- Simple and lightweight application  

## Installation  

1. Clone the repository:  
   ```bash
   git clone https://github.com/your-username/url-shortener.git
   cd url-shortener
   ```  

2. Install dependencies:  
   ```bash
   pip install pyshorteners
   ```  

## Usage  

1. Run the script:  
   ```bash
   python main.py
   ```  
2. Enter a long URL in the input field.  
3. Click the **Shorten URL** button to generate a short URL.  
4. The shortened URL will be displayed in the output field.  

## Requirements  
- Python 3.x  
- Tkinter (pre-installed with Python)  
- `pyshorteners` library
